# Expenso 

Expenso is a personal expense tracker that helps users manage their daily income and expenses efficiently.

## Features
- Add,edit and delete income and expenses
- User registration & login
- Categorize transactions
- View total balance
- Monthly summary
- Simple and user-friendly interface
